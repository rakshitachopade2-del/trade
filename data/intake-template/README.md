# Blank user-input template

Copy this directory into ignored private-data/ before inserting real material. It contains no market prices, filing figures or verified options membership.

The candidate session and mappings are suggestions to confirm against source files. `retention` starts unresolved, reviews are unconfirmed, adjustment is unknown, and the symbol list/candles are empty. Running this unchanged should report partial with exit 1.

Supply a permitted export and list, then edit manifest.json using [the schema](../../docs/MILESTONE_2A.md). For a filing, copy filing.template.json to filing.json, supply the document and actual metadata, and set manifest filing to filing.json. Leave unknown publication as unknown; do not invent a dissemination timestamp. Do not commit filled templates, documents or reports.
